NCR SUITE V2.22.4 - ORDRE D'INSTALLATION  

OBJECTIF   
Corriger l'echec de chargement du module PublicHomePage et des styles places
dans /assets, tout en conservant la vitrine animee. 
 
APPLICATION
1. Decompresser le ZIP V2.22.4.
2. Envoyer tous les fichiers et dossiers sur GitHub a la racine du depot.
3. Accepter le remplacement des fichiers portant le meme nom.
4. Attendre que le build et le deploiement Cloudflare soient termines.
5. Ouvrir https://ncr-suite.fr dans une fenetre privee. 
6. Verifier ensuite la page de connexion et la PWA installee.

SUPABASE
Aucun SQL a executer.

CLOUDFLARE
Aucune nouvelle variable d'environnement.
Le build reste : npm run build
Le dossier de sortie reste : dist

CACHE PWA ATTENDU
ncr-suite-shell-v2.22.4-asset-resilience

RESULTAT ATTENDU
- La vitrine animee s'affiche normalement.
- Aucun ecran HTML brut ne doit apparaitre.
- Aucun message "Failed to fetch dynamically imported module" ne doit rester.
- La PWA installee continue d'ouvrir la connexion.

Guide complet : docs/V2.22.4_INSTALLATION.md
