# NCR Suite V2.22.1 - Installation

La V2.22.1 modernise uniquement la vitrine publique. Elle part de la V2.22.0
déjà déployée et ne modifie ni la base Supabase, ni les comptes, ni les
automatisations, ni les fonctions métier.

## 1. SQL Supabase

Aucun SQL n’est nécessaire. Ne rejouez pas la migration `088` et ne modifiez
aucune table.

## 2. GitHub

1. Décompresser le ZIP V2.22.1.
2. Ouvrir le dépôt NCR Suite sur GitHub.
3. Envoyer tout le contenu du ZIP à la racine du dépôt en conservant les
   dossiers `src`, `public`, `scripts` et `docs`.
4. Remplacer les fichiers portant le même nom.
5. Valider le commit.

Ne pas supprimer les autres fichiers du dépôt. Ne pas envoyer `node_modules` ou
`dist`.

## 3. Cloudflare Pages

Le commit déclenche automatiquement le build. Vérifier que les étapes de
construction et de déploiement se terminent sans erreur.

Aucune nouvelle variable Cloudflare n’est nécessaire. Conserver :

```text
NCR_CANONICAL_REDIRECT_ENABLED=true
```

## 4. Cache PWA

Le nouveau cache attendu est :

```text
ncr-suite-shell-v2.22.1-premium-showcase
```

Après le déploiement :

1. fermer les onglets NCR Suite ;
2. ouvrir `https://ncr-suite.fr` dans une fenêtre privée pour contrôler la
   nouvelle page ;
3. revenir dans le navigateur normal et actualiser une fois ;
4. fermer puis rouvrir la PWA installée sur ordinateur ;
5. refaire le contrôle sur mobile.

## 5. Contrôle visuel

Vérifier sur ordinateur puis sur mobile :

1. le logo officiel est net dans l’en-tête ;
2. le symbole NCR Suite et les signaux animés sont visibles sur ordinateur ;
3. les boutons `Demander un accès` et `Se connecter` ouvrent les bonnes pages ;
4. l’aperçu du poste de pilotage reste entièrement visible ;
5. chacun des cinq métiers du catalogue affiche ses propres modules ;
6. aucun texte ne déborde sur le côté ;
7. la signature du pied de page est nette sur fond sombre ;
8. l’adresse reste `ncr-suite.fr`.

## 6. Ce qu’il ne faut pas refaire

- aucune action dans Supabase ;
- aucune modification IONOS ;
- aucune modification Brevo ;
- aucune Edge Function à redéployer ;
- aucune migration à exécuter.

## Retour arrière

En cas de problème visuel, restaurer simplement le dernier déploiement
Cloudflare V2.22.0. La base de données n’est pas concernée.
