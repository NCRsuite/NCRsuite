# NCR Suite V2.22.2 - Installation

La V2.22.2 finalise les animations de la vitrine, retire les repères graphiques
du hero et sépare le démarrage du site public de celui de la PWA installée. Elle
ajoute également une récupération automatique des anciens modules conservés
par le cache.

## 1. SQL Supabase

Aucun SQL n’est nécessaire. Ne rejouez pas la migration `088` et ne modifiez
aucune table.

## 2. GitHub

1. Décompresser le ZIP V2.22.2.
2. Ouvrir le dépôt NCR Suite sur GitHub.
3. Envoyer tout le contenu du ZIP à la racine du dépôt en conservant les
   dossiers `src`, `public`, `scripts` et `docs`.
4. Remplacer les fichiers portant le même nom.
5. Valider le commit.

Ne pas supprimer les autres fichiers du dépôt. Ne pas envoyer `node_modules` ou
`dist`.

## 3. Cloudflare Pages

Le commit déclenche automatiquement le build. Vérifier que la construction et
le déploiement se terminent sans erreur.

Aucune nouvelle variable Cloudflare n’est nécessaire. Aucun changement IONOS,
Brevo ou Supabase n’est demandé.

## 4. Cache PWA

Le nouveau cache attendu est :

```text
ncr-suite-shell-v2.22.2-motion-pwa-recovery
```

Après le déploiement :

1. fermer tous les onglets NCR Suite ;
2. ouvrir `https://ncr-suite.fr` dans une fenêtre privée ;
3. revenir dans le navigateur normal et actualiser une fois ;
4. fermer complètement la PWA installée ;
5. rouvrir la PWA depuis son icône.

La PWA doit arriver directement sur `Connexion`. Le navigateur normal doit
continuer à afficher la vitrine publique.

## 5. Ancien message de module

La V2.22.2 reconnaît notamment `Importing a module script failed`. Lors de sa
première détection, elle supprime automatiquement les caches NCR Suite,
réenregistre le Service Worker et recharge la page. Une protection de session
empêche toute boucle.

Si l’écran reste affiché après le premier rechargement, utiliser une seule fois
le bouton `Réinitialiser le cache`, puis fermer et rouvrir la PWA.

## 6. Contrôle visuel

Vérifier sur ordinateur :

1. aucune croix, aucun carré central et aucun repère bleu dans le hero ;
2. les quatre signaux se déplacent lentement sans recouvrir le titre ;
3. les boutons réagissent au survol et au clic ;
4. les cinq métiers actualisent le catalogue avec une transition courte.

Vérifier sur mobile :

1. les quatre signaux sont visibles sous le texte principal ;
2. les boutons réagissent au toucher ;
3. aucun texte ni élément ne déborde horizontalement ;
4. le défilement reste fluide.

## Retour arrière

En cas de problème visuel, restaurer le déploiement Cloudflare V2.22.1. La base
Supabase n’est pas concernée.
