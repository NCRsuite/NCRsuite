# NCR Suite V2.23.0 - Installation

## Ce qui change

La V2.23.0 transforme les deux sections les plus statiques de la vitrine en
véritables démonstrations commerciales :

- les quatre signaux du premier écran suivent des trajectoires plus visibles ;
- le parcours opérationnel montre la circulation de l’information de la
  collecte jusqu’à la décision ;
- les cinq métiers disposent d’un catalogue tarifaire sélectionnable ;
- les vingt offres reprennent les prix, capacités et fonctions du catalogue
  central déjà validé ;
- le logo du pied de page est désormais correctement dimensionné sur la page
  de demande d’accès.

Cette version synchronise aussi Supabase, le frontend et le Service Worker pour
supprimer l’alerte indiquant que l’application est plus récente que la
plateforme.

## Ordre obligatoire

### 1. Supabase

Confirmer d’abord qu’un point de retour ou une sauvegarde récente est
disponible, puis exécuter dans le SQL Editor :

```text
supabase/migrations/089_premium_showcase_offer_catalog.sql
```

Le script ne modifie aucune donnée métier. Il met uniquement à jour l’état de
release attendu :

```text
Base : 2.23.0
Frontend : 2.23.0
Cache : ncr-suite-shell-v2.23.0-premium-catalog
```

### 2. GitHub

Envoyer ensuite tout le contenu du ZIP à la racine du dépôt et accepter le
remplacement des fichiers existants.

Il ne faut supprimer aucun ancien fichier manuellement. Les anciens fichiers
de style peuvent rester présents pour permettre aux sessions déjà ouvertes de
terminer proprement leur actualisation.

### 3. Cloudflare

Conserver la configuration existante :

```text
Commande de build : npm run build
Dossier de sortie : dist
```

Aucune nouvelle variable d’environnement n’est requise.

Attendre le statut de déploiement réussi avant de tester le domaine.

### 4. Cache PWA

Le cache attendu est :

```text
ncr-suite-shell-v2.23.0-premium-catalog
```

Le nouveau nom force le remplacement de l’ancien cache lors de l’activation du
Service Worker. Fermer les anciens onglets, ouvrir `https://ncr-suite.fr` dans
une fenêtre privée, puis relancer la PWA installée. Un seul rechargement peut
être nécessaire si elle était encore ouverte pendant le déploiement.

## Contrôles fonctionnels

Ouvrir successivement :

```text
https://ncr-suite.fr/
https://ncr-suite.fr/demande-acces
https://ncr-suite.fr/connexion
```

Vérifier :

1. Les quatre blocs du premier écran se déplacent selon des trajectoires
   distinctes.
2. La progression traverse le parcours Collecter, Orchestrer, Prouver et
   Piloter.
3. Les cinq boutons métier changent réellement le catalogue tarifaire.
4. Chaque métier affiche Découverte, Essentielle, Professionnelle et Métier.
5. Les tarifs restent lisibles sur ordinateur et mobile.
6. Le logo NCR Suite est visible dans le pied de page de la demande d’accès.
7. L’espace d’administration n’affiche plus l’écart `2.22.4 / 2.22.0`.

## Résultat technique validé

La commande `npm run build` valide successivement les styles publics, l’audit
statique, les parcours critiques, la préparation de release, TypeScript et le
bundle Vite. Le démarrage reste regroupé dans
`ncr-suite-app-v230.js` et ne dépend d’aucun fragment critique dans
`/assets`.
