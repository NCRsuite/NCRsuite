# NCR Suite V2.22.3 - Installation

La V2.22.3 corrige l’affichage HTML brut observé sur Safari sans retirer les
animations de la vitrine. Une feuille légère contenant les styles publics est
chargée avant le style général de l’application.

## 1. SQL Supabase

Aucun SQL n’est nécessaire. Ne rejouez pas la migration `088`.

## 2. GitHub

1. Décompresser le ZIP V2.22.3.
2. Envoyer tout son contenu à la racine du dépôt GitHub.
3. Remplacer les fichiers portant le même nom.
4. Ne supprimer aucun autre fichier du dépôt.
5. Valider le commit.

Le build génère automatiquement :

```text
public/ncr-suite-showcase-v2223.css
```

## 3. Cloudflare Pages

Attendre que la construction puis le déploiement soient terminés. Le patch
ajoute des types de contenu explicites :

```text
CSS        text/css; charset=utf-8
JavaScript text/javascript; charset=utf-8
```

Aucune variable Cloudflare supplémentaire n’est nécessaire.

## 4. Fonctionnement visuel

Au chargement, Safari affiche brièvement un écran NCR Suite propre. Dès que les
styles sont prêts, cet écran disparaît en fondu et la vitrine complète apparaît
avec :

- l’introduction animée ;
- les quatre indicateurs flottants ;
- les animations au défilement ;
- les réactions au survol, au clic et au toucher ;
- les transitions du catalogue métier.

Le patch ne remplace donc pas la vitrine par une page statique.

## 5. Récupération automatique

Si les styles sont indisponibles, NCR Suite effectue une seule récupération du
cache et recharge la page. Une protection de session empêche toute boucle. Si
le second chargement échoue encore, un écran propre propose `Recharger` au lieu
d’afficher le HTML brut.

## 6. Cache PWA

Le cache attendu est :

```text
ncr-suite-shell-v2.22.3-safari-styles
```

Après le déploiement :

1. ouvrir `https://ncr-suite.fr` en navigation privée sur Safari ordinateur ;
2. refaire le test en navigation privée sur mobile ;
3. revenir dans le navigateur normal et actualiser une fois ;
4. fermer puis rouvrir la PWA installée.

La PWA doit toujours ouvrir directement la connexion.

## Retour arrière

En cas de problème, restaurer le déploiement Cloudflare V2.22.2. La base
Supabase n’est pas concernée.
