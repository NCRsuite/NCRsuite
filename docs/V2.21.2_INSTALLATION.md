# NCR Suite V2.21.2

## Objet

La V2.21.2 termine le cycle prévu avec une validation production unique, visible dans **Administration NCR > Surveillance** par le super-administrateur.

Elle ne remplace pas les outils de surveillance existants. Elle les réunit dans un verdict de mise en production, ajoute les contrôles Formation récents et conserve une preuve horodatée de chaque validation enregistrée.

## Contrôles automatiques

Le rapport vérifie :

- la cohérence entre la version Supabase, le frontend et le cache PWA ;
- la présence des tables et fonctions critiques ;
- les règles RLS et les fonctions publiques ;
- la présence d’un propriétaire actif dans chaque entreprise ouverte ;
- la cohérence des formules et abonnements ;
- les erreurs remontées par les navigateurs et les anciennes versions encore actives ;
- les files d’e-mails et de notifications push ;
- les documents Formation en échec ou bloqués ;
- les imports récents avec erreurs ou restés en traitement ;
- les sessions sans stagiaire ou sans formateur ;
- les invitations d’espace expirées et les signatures en retard ;
- les demandes de modules Formation à traiter.

Chaque résultat indique soit **Validé**, **À surveiller** ou **Bloquant**, avec l’action à réaliser.

## Validation manuelle

Avant l’enregistrement du contrôle, le super-administrateur confirme :

1. la migration Supabase et la version active ;
2. la réussite du build Cloudflare ;
3. le renouvellement du cache PWA sur ordinateur et mobile ;
4. les principaux rôles utilisateurs ;
5. un parcours critique pour chaque métier actif ;
6. les automatisations, portails, signatures et imports Formation ;
7. la sauvegarde Supabase et la procédure de retour arrière.

Un contrôle peut être enregistré avec des anomalies automatiques afin de conserver la preuve d’un essai bloqué. Il ne peut pas être enregistré sans les sept confirmations manuelles.

## Déploiement

### 1. Supabase

Exécuter intégralement :

`supabase/migrations/084_final_production_validation.sql`

Contrôler ensuite :

```sql
select
  database_version,
  expected_frontend_version,
  expected_pwa_cache
from public.platform_release_state
where singleton = true;
```

Résultat attendu :

```text
2.21.2 | 2.21.2 | ncr-suite-shell-v2.21.2-final-production-validation
```

La migration crée l’historique `platform_production_validation_runs` et deux fonctions réservées au super-administrateur. Aucune fonction Edge supplémentaire n’est nécessaire.

### 2. GitHub

Envoyer tous les fichiers du patch en conservant leur arborescence. Vérifier que `package.json` affiche `2.21.2`.

### 3. Cloudflare

Le build reste :

```text
npm run build
```

Le dossier de sortie reste `dist`. Le journal doit annoncer `ncr-suite@2.21.2`, puis confirmer l’audit statique, les parcours critiques et la préparation de release.

### 4. Cache PWA

Fermer tous les onglets NCR Suite, puis rouvrir l’application. Répéter l’opération sur les appareils mobiles utilisés pour les tests.

Cache attendu :

```text
ncr-suite-shell-v2.21.2-final-production-validation
```

### 5. Verdict final

1. Ouvrir **Administration NCR > Surveillance**.
2. Repérer **Validation production finale**.
3. Cliquer sur **Relancer**.
4. Corriger les points bloquants et examiner chaque avertissement.
5. Cocher les sept confirmations manuelles.
6. Cliquer sur **Enregistrer ce contrôle**.
7. Vérifier que le verdict apparaît dans l’historique.
8. Télécharger le rapport JSON ou CSV et l’export de l’historique.

## Lecture du verdict

- **Prête pour la production** : aucun blocage ni avertissement automatique, et la liste manuelle est terminée.
- **Vérifications à terminer** : au moins un avertissement reste présent ou la liste manuelle n’est pas terminée.
- **Mise en production bloquée** : au moins un contrôle automatique critique doit être corrigé.

## Retour arrière

La migration est additive et idempotente. Si le build GitHub ou Cloudflare échoue, ne pas valider la production. Corriger le patch puis relancer le même déploiement. Une ancienne interface détectera automatiquement le décalage de version jusqu’à la mise en ligne complète de la V2.21.2.
