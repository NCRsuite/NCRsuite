# NCR Suite V2.22.4 - Installation

## Ce que corrige cette version

La production chargeait correctement le fichier principal, mais échouait sur
le module dynamique de la page d’accueil et sur le style général placé dans
`/assets`. La V2.22.4 retire ces deux dépendances du démarrage critique.

La vitrine reste intégralement animée.

## Ordre d’installation

1. Décompresser le ZIP V2.22.4.
2. Envoyer l’ensemble de son contenu à la racine du dépôt GitHub.
3. Accepter le remplacement des fichiers existants.
4. Attendre la fin du build Cloudflare.
5. Vérifier que le déploiement est indiqué comme réussi.

Il n’y a aucun SQL à exécuter et aucune variable à ajouter.

## Fichiers essentiels

```text
public/ncr-suite-showcase-v2224.css
public/ncr-suite-app-v2224.css
dist/ncr-suite-app-v2224.js
public/_headers
public/sw.js
vite.config.ts
index.html
```

Les deux feuilles CSS sont générées automatiquement par `npm run build`.

## Vérification après déploiement

Ouvrir successivement :

```text
https://ncr-suite.fr/
https://ncr-suite.fr/connexion
```

Effectuer le contrôle dans une navigation privée sur ordinateur puis sur
mobile. La vitrine doit conserver son introduction, ses signaux flottants, ses
apparitions au défilement et les transitions du catalogue métier.

La PWA installée doit continuer d’ouvrir directement la connexion.

## Cache

Le cache attendu est :

```text
ncr-suite-shell-v2.22.4-asset-resilience
```

Le changement de nom force le remplacement de l’ancien cache lors de
l’activation du nouveau Service Worker.
