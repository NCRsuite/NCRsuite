# NCR Suite V2.27.1

Base SaaS multi-métier NCR Suite.

Cette version affine l’expérience de l’espace connecté sans modifier les
fonctionnalités métier déjà validées. Les changements de pages, filtres,
indicateurs, confirmations et chargements deviennent plus fluides et plus
lisibles sur ordinateur comme sur mobile.

Les principaux tableaux de bord affichent désormais des états de chargement
élégants afin d’éviter les faux zéros et les contenus qui apparaissent
brutalement. Le réglage système de réduction des animations est respecté.

Consulter uniquement `A_LIRE_INSTALLATION_V2.27.1.txt` avant déploiement.
