# NCR Suite V2.22.2

Base SaaS multi-métier NCR Suite.

Cette version finalise la première impression de `https://ncr-suite.fr` avec des animations plus vivantes, des interactions tactiles professionnelles et une composition débarrassée de ses repères techniques. La PWA installée ouvre désormais directement la connexion et récupère automatiquement un cache obsolète après une mise à jour.

Le lancement commercial, les accès contrôlés et toutes les fonctions métier déjà validées restent inchangés. Aucun SQL supplémentaire n’est nécessaire.

Consulter `A_LIRE_INSTALLATION_V2.22.2.txt` avant déploiement.
