# NCR Suite V2.29.0

Base SaaS multi-métier NCR Suite.

Cette version automatise le contrat de première souscription : génération du PDF,
validation par code e-mail, preuve horodatée, archivage privé et ouverture de
Stripe uniquement après signature. Les contrats restent accessibles depuis
`Mon abonnement`. La vitrine et le référencement restent inchangés.

Consulter uniquement `A_LIRE_INSTALLATION_V2.29.0.txt` pour déployer ce patch.
