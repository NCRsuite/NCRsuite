# NCR Suite V2.26.0

Base SaaS multi-métier NCR Suite.

Cette version finalise le cycle commercial Stripe : catalogue administrable,
paiement obligatoire avant ouverture, changements de formule, modules
récurrents, délai de grâce et résiliation.

Une rétrogradation retire uniquement les droits devenus indisponibles. Les
données existantes restent stockées et redeviennent accessibles après une
remontée en gamme compatible.

Consulter uniquement `A_LIRE_INSTALLATION_V2.26.0.txt` avant déploiement.
